**Ayu Dawn** is a color theme based on [ayu](https://github.com/ayu-theme/vscode-ayu). Its Mirage theme is exactly like Ayu Mirage, but with a slightly paler background and brighter application text and icons, which I find easier on my eyes.

## Install

[Install from the Marketplace](https://marketplace.visualstudio.com/items?itemName=GregPasquariello.ayu-dawn), or run:

```shell
ext install GregPasquariello.ayu-dawn
```

Then go to `Preferences > Color Theme` and select **Ayu Dawn Mirage**.

To enable file icons: `Preferences > File Icon Theme > Ayu Dawn`.

### Unbordered

Ayu Dawn Mirage also comes as **Ayu Dawn Mirage Unbordered**: no dividers between the side bar, editor, panel, title bar and status bar, so the whole window reads as one surface. In VS Code's modern UI the panels sit flush instead of floating as separate islands.

## What's included

- **Mirage color theme**: bordered and unbordered, with support for VS Code's modern UI
- **File icons**: Custom icon theme included
- **[Iosevka font](https://github.com/gpasq/vscode-ayu-dawn/tree/master/fonts)**: Bundled for a consistent look
